# BS2 紅色 vs 紫色 — AI 訓練規則

## 對局檔案

- **玩家牌組**: BS2 紅色
- **AI 牌組**: BS2 紫色
- **勝率 (AI)**: 52.0% (26/50)
- **平均回合數**: 13.4
- **卡住場次**: 0

---

## 關鍵發現

### 紅色為何獲勝

1. **快速累積等級破壞**: 紅色的侵略性餅乾陣容造成集中傷害
2. **更高 Lv3 密度**: 紅色的破壞區經常包含多個 Lv3 餅乾
3. **支援協同**: 紅色的支援卡更有效地放大攻擊傷害
4. **高效交換**: 紅色犧牲低價值餅乾來消除高價值目標

### 紫色為何落敗

1. **干擾協同**: 紫色的效果與紅色的侵略性協同良好
2. **節奏控制**: 紫色能控制節奏並阻礙紅色的支援佈局
3. **風行弓箭手 Lv3**: 強大的後期威脅

---

## AI 訓練規則

### 規則 1：侵略性前期

```
規則: 紅色前期侵略對紫色
優先級: 高
條件: 第 1-8 回合
動作:
  - 立即部署最高等級的餅乾（時光守護者 Lv3、閃電泡芙 Lv3、黑莓 Lv3）
  - 每回合都發動攻擊（如果合法）
  - 放置能提升攻擊傷害的支援卡
理由: 紅色的優勢是侵略性。紫色的干擾較慢。施加前期壓力。
```

### 規則 2：集中傷害

```
規則: 紅色集中傷害對紫色
優先級: 高
條件: 紫色戰鬥區有多個餅乾
動作:
  - 將攻擊集中在紫色最弱的餅乾直到擊倒
  - 不要將傷害分散到多個餅乾
  - 擊倒後立即轉向下一個最弱目標
理由: 擊倒餅乾有助於達成等級破壞上限。分散傷害會浪費攻擊。
```

### 規則 3：等級破壞意識

```
規則: 紅色監控與紫色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：紫色等級破壞 + 我的當前攻擊 >= 12？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：Lv3 餅乾優先

```
規則: 紅色優先部署 Lv3 餅乾對紫色
優先級: 高
條件: 多個紅色餅乾可部署
動作:
  - 優先部署 Lv3 餅乾（時光守護者、閃電泡芙、黑莓）
  - 若多個 Lv3 可用，選擇有最佳登場效果的
  - 除非沒有其他選擇，否則避免部署 Lv1
理由: Lv3 餅乾較難被擊倒，且在被擊倒時對等級破壞貢獻更多。
```

### 規則 5：致命偵測

```
規則: 紅色對紫色的致命偵測
優先級: 極高
條件: 紫色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 紫色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```

- **紅色的優勢**: 侵略性餅乾陣容、集中傷害
- **關鍵窗口**: 第 13-18 回合（75.9% 的落敗）
- **勝利條件**: 等級破壞上限（98.7%）
