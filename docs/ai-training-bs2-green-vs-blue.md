# BS2 豆子 vs 藍色 — AI 訓練規則

- **玩家牌組**: BS2 豆子
- **AI 牌組**: BS2 藍色
- **勝率 (AI)**: 56.0% (28/50)
- **平均回合數**: 16.9
- **卡住場次**: 0

## 關鍵發現

### 豆子為何獲勝

1. **陷阱協同**: 豆子的陷阱（BS2-021）提供防禦價值
2. **支援型策略**: 豆子的支援卡隨時間複合累積
3. **後期強度**: 豆子的 Lv3 餅乾在建立後非常強大

### 藍色為何落敗

1. **佈局較快**: 藍色的海精靈餅乾 Lv3 能快速建立
2. **抽牌優勢**: 藍色的抽牌效果維持手牌優勢
3. **前期壓力**: 藍色能在豆子建立之前施加壓力

## AI 訓練規則

### 規則 1：防禦性陷阱使用

```
規則: 豆子對藍色的防禦性陷阱使用
優先級: 高
條件: 藍色攻擊高價值餅乾
動作:
  - 使用陷阱保護 Lv3 餅乾
  - 不要在 Lv1 餅乾上浪費陷阱
  - 考慮每次防禦決定對等級破壞的影響
理由: 保護高價值餅乾能阻止藍色獲得等級破壞進度。
```

### 規則 2：支援卡部署

```
規則: 豆子對藍色的支援卡部署
優先級: 中
條件: 支援階段
動作:
  - 在進入主要階段前部署提升攻擊的道具/舞台
  - 優先選擇影響多個餅乾的卡牌
  - 不要囤積支援卡 — 盡早部署以獲得累積效益
理由: 支援效果隨多個回合複合累積。延遲部署會浪費價值。
```

### 規則 3：等級破壞意識

```
規則: 豆子監控與藍色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：藍色等級破壞 + 我的當前攻擊 >= 10？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：後期優勢

```
規則: 豆子利用後期優勢對藍色
優先級: 中
條件: 第 12 回合以後
動作:
  - 豆子的 Lv3 餅乾在建立後非常強大
  - 使用支援卡提升攻擊傷害
  - 不要急躁 — 豆子的優勢在後期
理由: 豆子的支援型策略需要時間建立，但準備好後非常強大。
```

### 規則 5：致命偵測

```
規則: 豆子對藍色的致命偵測
優先級: 極高
條件: 藍色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 藍色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```
