# BS2 紅色 vs 藍色 — AI 訓練規則

## 對局檔案

- **玩家牌組**: BS2 紅色
- **AI 牌組**: BS2 藍色
- **勝率 (AI)**: 66.0% (33/50)
- **平均回合數**: 14.6
- **卡住場次**: 0

---

## 關鍵發現

### 紅色為何獲勝

1. **快速累積等級破壞**: 紅色的侵略性餅乾陣容造成集中傷害
2. **更高 Lv3 密度**: 紅色的破壞區經常包含多個 Lv3 餅乾
3. **支援協同**: 紅色的支援卡更有效地放大攻擊傷害
4. **高效交換**: 紅色犧牲低價值餅乾來消除高價值目標

### 藍色為何落敗

1. **佈局較慢**: 藍色的海精靈餅乾 Lv3 需要時間建立
2. **依賴抽牌**: 藍色需要穩定抽牌來維持手牌優勢
3. **前期脆弱**: 藍色的前期餅乾是紅色的理想目標

---

## AI 訓練規則

### 規則 1：侵略性前期

```
規則: 紅色前期侵略對藍色
優先級: 高
條件: 第 1-8 回合
動作:
  - 立即部署最高等級的餅乾（時光守護者 Lv3、閃電泡芙 Lv3、黑莓 Lv3）
  - 每回合都發動攻擊（如果合法）
  - 放置能提升攻擊傷害的支援卡
理由: 紅色的優勢是侵略性。藍色的佈局較慢。施加前期壓力。
```

### 規則 2：集中傷害

```
規則: 紅色集中傷害對藍色
優先級: 高
條件: 藍色戰鬥區有多個餅乾
動作:
  - 將攻擊集中在藍色最弱的餅乾直到擊倒
  - 不要將傷害分散到多個餅乾
  - 擊倒後立即轉向下一個最弱目標
理由: 擊倒餅乾有助於達成等級破壞上限。分散傷害會浪費攻擊。
```

### 規則 3：等級破壞意識

```
規則: 紅色監控與藍色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：藍色等級破壞 + 我的當前攻擊 >= 10？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：Lv3 餅乾優先

```
規則: 紅色優先部署 Lv3 餅乾對藍色
優先級: 高
條件: 多個紅色餅乾可部署
動作:
  - 優先部署 Lv3 餅乾（時光守護者、閃電泡芙、黑莓）
  - 若多個 Lv3 可用，選擇有最佳登場效果的
  - 除非沒有其他選擇，否則避免部署 Lv1
理由: Lv3 餅乾較難被擊倒，且在被擊倒時對等級破壞貢獻更多。
```

### 規則 5：致命偵測

```
規則: 紅色對藍色的致命偵測
優先級: 極高
條件: 藍色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 藍色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```

- **藍色的關鍵威脅**: 海精靈餅乾 Lv3、抽牌效果
- **紅色的優勢**: 侵略性餅乾陣容、集中傷害
- **關鍵窗口**: 第 13-18 回合（75.9% 的落敗）
- **勝利條件**: 等級破壞上限（98.7%）
