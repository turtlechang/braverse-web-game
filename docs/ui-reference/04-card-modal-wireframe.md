## B. 效果決策 modal（陷阱/FLIP/物品/昏厥/抽牌/棄牌 共用）

```
┌── 深色 backdrop（加深，聚焦） ──────────────────┐
│  標題：對手宣告攻擊——是否發動陷阱？    [－縮小]  │
│  ┌────────────┬──────────────────────────┐    │
│  │ 攻擊者卡圖  │ 步驟 1/2：選擇要發動的陷阱  │    │
│  │ （情境卡）  │ ○ ST4-021 …（費用 {B}）    │    │
│  │            │ ○ 不發動                   │    │
│  └────────────┴──────────────────────────┘    │
│        [確認發動]（主）   [略過]（次，可略過時）  │
└─────────────────────────────────────────────────┘
   縮小後 → 右下 dock：[▲ 陷阱回應（進行中）]
```

## 規格

| 規則 | 內容 |
|---|---|
| 版式 | 寬版雙欄：左情境卡圖、右步驟選項；多步驟顯示 step 進度 |
| 縮小 dock | 所有需要看盤的決策必備；dock 點擊返回原狀態 |
| 語意 | 強制效果只給「確認結算」，不得出現「略過」字樣；可略過才有次按鈕 |
| 付款 | 能量支付候選依顏色過濾（回歸熱點）；同卡不可同時付能量與特殊代價 |
| 順序 | 同時觸發效果先由玩家選順序（清單 modal） |
| 鍵盤 | `Escape`=取消/縮小（不等於略過）；focus trap 在 modal 內 |
