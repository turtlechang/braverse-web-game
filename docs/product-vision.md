# 產品願景（Product Vision）

最後更新：2026-07-10

## 1. 定位

《薑餅人對戰卡牌 Braverse Web Game》是 **CookieRun: Braverse TCG 的非官方粉絲研究 / 學習型網頁實作**。

- 目的：研究 TCG 規則引擎設計、AI 對弈與數位卡牌 UI/UX，並讓玩家能在瀏覽器體驗 Braverse 對局。
- **不是**官方產品；與 Devsisters 無任何合作、授權或背書關係。
- 不商用、不收費、不做金流；素材政策見 [ip-and-asset-policy.md](ip-and-asset-policy.md)。

## 2. 目標使用者

1. Braverse 實體卡玩家：想練習對局、測試牌組。
2. TCG 愛好者：想快速理解 Braverse 規則。
3. 開發者（含專案作者）：研究規則引擎、AI、卡牌資料管線的參考實作。

## 3. 產品支柱（第一版）

| 支柱 | 內容 | 狀態 |
|---|---|---|
| A. 單機 AI 對戰 | 完整可玩一局：開局、調度、五階段回合、攻防、效果、勝負 | ✅ 已達成（Lv.1–4 AI） |
| B. 牌組編輯器 | 搜尋、篩選、合法性即時檢查、匯入匯出、保存 | ✅ 已達成 |
| C. UI/UX 重製 | 接近市面數位 TCG 的可讀性：清楚場區、可行動提示、效果提示框、動畫 | ✅ 持續迭代 |
| D. 簡易線上對戰 | 房間碼、無帳號、規則層擋非法操作 | ✅ MVP 已進 main，待驗收 |

## 4. 體驗原則

1. **玩家不需要猜現在可以做什麼**：階段列、CTA、可行動高亮、不合法操作即時可讀錯誤。
2. **規則正確優先於視覺華麗**：所有操作經規則層驗證，UI 不另寫規則。
3. **對局可重現**：種子洗牌 + commandLog，利於回報問題與回歸測試。
4. **桌機優先，RWD 為輔**：16:9 完整遊玩、1366×768 不爆版、最低 600×338。
5. **AI 是練習對象不是黑箱**：分級明確、決策可 debug、有訓練文件佐證強度。

## 5. 明確不做（Non-goals）

- 帳號系統、金流、排行榜、配對系統、營運後台。
- 完整防作弊方案（線上 MVP 僅靠伺服器權威狀態 + 視角遮罩）。
- 官方素材的再散布或商用包裝。
- 宣稱規則裁定為官方立場（專案裁定記錄於 [rule-clarifications.md](rule-clarifications.md)）。

## 6. 完成定義（對照總體計畫）

1. ✅ 單機 AI 對戰可完整玩一局。
2. ✅ 牌組編輯器可建立合法 60 張牌組。
3. ⚠️ 卡牌資料庫可驗證、可擴充、可匯入（缺 `validate:cards` 獨立驗證）。
4. ✅ UI 有清楚場區、卡牌互動、回合提示。
5. ⚠️ UI reference 文件（實作超前文件，wireframe 補寫價值待議）。
6. ✅ 簡易線上對戰 MVP，不需帳號（待雙視窗完整驗收）。
7. ⚠️ 可部署 Vercel（前端可；ws server 需另覓宿主）。
8. ✅ 有 CI 檢查。
9. ✅ 有 README、AGENTS.md、docs 文件。
10. ⚠️ 新卡牌更新與版本維護流程（有 checklist 與 Skills，缺正式流程文件）。
