# BS2 黃色 vs 紫色 — AI 訓練規則

## 對局檔案

- **玩家牌組**: BS2 黃色
- **AI 牌組**: BS2 紫色
- **勝率 (AI)**: 44.0% (22/50)
- **平均回合數**: 14.0
- **卡住場次**: 0

---

## 關鍵發現

### 黃色為何獲勝

1. **平衡打法**: 黃色混合進攻與干擾
2. **手牌控制**: 黃色的棄牌效果拖慢紫色的佈局
3. **節奏適中**: 黃色不過度擴展，保持等級破壞在可控範圍

### 紫色為何落敗

1. **干擾協同**: 紫色的效果與黃色的平衡打法協同良好
2. **節奏控制**: 紫色能控制節奏並阻礙黃色的支援佈局
3. **風行弓箭手 Lv3**: 強大的後期威脅

## AI 訓練規則

### 規則 1：節奏控制

```
規則: 對紫色的節奏控制
優先級: 高
條件: 始終
動作:
  - 不要過度擴展 — 保持場面在可控範圍
  - 使用干擾效果拖慢紫色的佈局
  - 維持手牌優勢以保持靈活性
理由: 紫色的優勢來自干擾。控制節奏能否定其優勢。
```

### 規則 2：目標選擇

```
規則: 集中傷害在弱小紫色餅乾
優先級: 高
條件: 紫色戰鬥區有多個餅乾
動作:
  - 將攻擊集中在紫色最弱的餅乾直到擊倒
  - 不要將傷害分散到多個餅乾
  - 擊倒後立即轉向下一個最弱目標
理由: 擊倒餅乾有助於達成等級破壞上限。分散傷害會浪費攻擊。
```

### 規則 3：等級破壞意識

```
規則: 監控與紫色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：紫色等級破壞 + 我的當前攻擊 >= 12？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：前期侵略

```
規則: 對紫色的前期侵略
優先級: 中
條件: 第 1-8 回合
動作:
  - 立即部署最高等級的餅乾
  - 每回合都發動攻擊（如果合法）
  - 放置能提升攻擊傷害的支援卡
理由: 紫色的干擾較慢。施加前期壓力能阻止其建立控制。
```

### 規則 5：致命偵測

```
規則: 對紫色的致命偵測
優先級: 極高
條件: 紫色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 紫色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```
