# 視覺風格指南（Visual Style Guide）

最後更新：2026-07-10。基準取自現行 `src/App.css` 實際用色，加上 W3/W5（甜點戰場）擴充色。方向：**深藍夜空桌墊 + 糖果色點綴 + 高對比功能色**；裝飾永遠讓位給可讀性。

## 1. 色彩

### 基底（現行已用）

| 用途 | 色值 | 備註 |
|---|---|---|
| 桌墊底 | `#07162f` + 漸層 `rgba(8,38,89,.96) → rgba(22,62,126,.9)` | 全畫面背景 |
| 面板底 | `rgba(7,27,61,.78)`、`rgba(5,21,52,.62)` | 半透明深藍，疊在桌墊上 |
| 主文字 | `#eef9ff` | 標題與重點 |
| 次文字 | `#9fc3e8` | 說明、meta 資訊 |
| 弱化文字 | `rgba(210,226,252,.55)` | footer、輔助字 |

### 功能色（現行已用）

| 用途 | 色值 |
|---|---|
| 主要 accent / 可行動 | `#7ee7f0`（青）＋光暈 `rgba(82,230,255,.22)` |
| 警示 / 傷害 | `#ff8b74` 系（`rgba(255,139,116,.48)` 邊框）、錯誤文字 `#e05252` |
| 強調 / 回合提示 | `rgba(255,214,111,.72)`（琥珀） |
| 卡牌能量五色 | 紅/黃/綠/藍/紫沿用官方能量圖示色，UI 不重定義 |

### 甜點點綴色（W3/W5 擴充，僅裝飾）

| 名稱 | 色值 | 用途 |
|---|---|---|
| 草莓糖 | `#ff9db8` | 主選單標題漸層、勝利彩帶 |
| 奶油黃 | `#ffd66f` | 既有琥珀的亮階，徽章高光 |
| 薄荷 | `#8ef0c8` | 增益數值閃爍 |
| 餅乾棕 | `#8a5a3b` | 桌墊紋理暗紋（低對比，透明度 ≤8%） |

規則：點綴色不得作為唯一的資訊載體（色弱可辨）；狀態一律「顏色＋形狀/文字」雙編碼。

## 2. 字體與層級

- 字族：系統字疊（`system-ui, "Noto Sans TC", sans-serif`），不引入 webfont（bundle 與授權考量）。
- 層級：畫面標題 1.4–1.6rem/800；區段標籤 0.76rem/800/`letter-spacing:.12em`/青色（現行慣例）；本文 0.9–1rem；輔助 0.68–0.76rem。
- 數字（HP/ATK/張數）用 700 以上字重＋徽章底，掃視可讀。

## 3. 形狀、深度與間距

- 圓角：面板/區域 12px、卡牌 8px、按鈕 8px、徽章全圓。
- 陰影（W3 目標）：卡牌兩層——環境 `0 8px 24px rgba(3,14,36,.45)` + 接觸 `0 2px 6px rgba(3,14,36,.6)`；modal 用更深的單層。
- 間距節奏：4 的倍數（4/8/12/16/24/28）；場地區塊 gap 現行 18px 保留。
- 邊框：可互動元素 1px `rgba(126,231,240,.28)`；選取/可行動時升為實色青光。

## 4. 互動狀態（每個可點擊區域必備）

| 狀態 | 規格 |
|---|---|
| hover | 邊框亮起或上移 ≤8px；卡牌加 scale ≤1.02（手牌保留扇形角度） |
| active/選取 | 青色實邊 + 光暈；同時只有一個主選取 |
| disabled | 透明度 .45 + 去光暈 + `cursor:not-allowed`（達 4 張上限卡池卡的現行樣式為準） |
| 危險操作 | 刪除類按鈕紅系 + 二次確認 |
| focus-visible | 與 hover 同視覺 + 2px outline（鍵盤可達） |

## 5. 動效

- 時長：微回饋 120–200ms、卡牌移動 200–300ms、modal 進出 150ms；ease-out。
- 既有：攻擊抖動、抽牌滑入、傷害閃爍、昏厥縮小、phase-glow。
- W2：所有動效統一走 CSS class，「減少動畫」設定與 `prefers-reduced-motion` 時長歸零。
- 禁止：阻塞輸入的長動畫、循環吸睛動畫。

## 6. 提示框（modal）規範

- 深色置中（`modal-backdrop` 加深背景）、寬版雙欄可容卡圖＋選項（PR #21 定案）。
- 一律提供：明確主按鈕、可略過時的次按鈕、可縮小 dock（看盤後可返回）。
- 禁止淺色浮窗遮牌桌；禁止把強制效果寫成「略過」語意。

## 7. 無障礙底線

- 文字對比 ≥ 4.5:1（弱化文字至少 3:1 且不承載關鍵資訊）。
- 全鍵盤可操作：選取/取消（`Escape`）已有，新增互動需保留。
- 色彩雙編碼；`aria-label` / `role="dialog"` 慣例延續。
