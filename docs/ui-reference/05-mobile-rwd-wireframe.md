# Wireframe 05 — 行動裝置 / 窄視窗 RWD

最後更新：2026-07-10。定位：**桌機優先，手機/平板為輔**（可瀏覽與簡化操作）。現行斷點：<900px 窄版戰場、<680px 主選單單欄；最低支援 600×338。

## 窄版戰場（<900px，現行）

```
┌────────────────────────────────────┐
│ 頂部階段列（五階段橫列＋當前高亮）      │
├────────────────────────────────────┤
│ 對手支援區（45%，縮小卡）             │
│ 對手戰鬥區（55%）                    │
│ ── 中央分隔列（操作提示） ──          │
│ 我方戰鬥區（55%）                    │
│ 我方支援區（45%）                    │
├────────────────────────────────────┤
│ 我方手牌（扇形，縮小）                │
│ 底部工具列：CTA／資源牌堆／紀錄        │
└────────────────────────────────────┘
```

- 維持 55/45 比例與零捲軸；HUD 上下排列。
- 手牌選取 → 抬升＋合法動作按鈕（同桌機）。
- 效果 modal 同一套（置中深色、可縮小）。

## 直式手機（未來優化，僅規劃）

現況：直式極窄（<600px 寬）未特別優化，可橫持遊玩。若投入直式支援，原則：

1. 戰場直式堆疊，卡牌改「橫條列」呈現（卡名＋HP/ATK 徽章），點擊展開卡圖。
2. 手牌改底部橫向捲軸列（不扇形）。
3. 所有 hover 行為改「單擊選取、再擊確認」；長按＝放大預覽（W1 觸控版）。
4. 觸控目標 ≥44px。
