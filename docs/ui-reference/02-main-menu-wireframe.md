## 行為規格

| 元素 | 行為 |
|---|---|
| 主 CTA（空狀態） | 無自訂牌組時「建立第一副牌組」（`.main-menu-primary.main-menu-create-first`）為 primary；「對戰入口」呈 disabled 樣式並顯示原因文字「尚無自訂牌組，請先建立牌組後再開始對戰。」（2026-07-11 P0 修正，見 CHANGELOG） |
| 主 CTA（有牌組） | 「對戰入口」還原為 primary；需選定合法牌組才可進，不合法時錯誤區列原因 |
| 線上對戰 | 開 `OnlineMatchPanel`（見 [Wireframe 06](06-online-match-wireframe.md)），不受牌組是否存在限制（面板內建立/加入房間才需選牌組） |
| 牌組卡 | 點選=設為目前牌組；「需調整」hover 顯示不合法原因；刪除需確認 |
| AI 對手 | 牌組下拉（隨機/五色起始/第二彈五組）＋等級下拉（Lv.1–4，附說明句） |
| footer | 非官方聲明常駐、`pointer-events` 不干擾 |

## 狀態

- 無牌組：左欄主 CTA 切換為「建立第一副牌組」＋「對戰入口」disabled；右欄空狀態引導「進入牌組編輯器建立第一副」。
- 有牌組：左欄「對戰入口」還原為 primary。
- <680px：單欄直列（heading→actions→status→errors→decks）。

- **W5**：標題字標加草莓糖→奶油黃漸層；牌組卡加代表色條（依牌組主色）；主按鈕保留青色體系。
