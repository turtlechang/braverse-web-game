## 區域規格

| 區域 | 行為 |
|---|---|
| PhaseRail（左欄） | 五階段直列，當前階段高亮 + phase-glow；下方精確 CTA（略過支援階段／結束主要階段／結束回合），MatchToolbar（重置/牌組/暫停）在其上方 |
| 中央分隔列 | 攻擊宣告、付款選擇、目標選擇的提示唯一集中處；平時顯示簡短操作指引 |
| 戰鬥區 | 雙方 55%；卡牌向中央靠攏；橫置＝已攻擊；HP/ATK 徽章常駐；可行動卡青色光暈 |
| 支援區 | 雙方 45%；我方左→右、對手右→左；橫置＝已付款能量；hover 顯示放大預覽（W1） |
| 資源牌堆 | 牌庫/場景/休息區為數字牌堆 + hover 浮層（休息等級、場景橫置狀態）；棄牌/牌組清單開大型視窗 |
| 手牌 | 扇形；選取後抬升並顯示單一合法動作按鈕；空白處或 `Escape` 取消；不可操作卡降權顯示 |
| 戰鬥紀錄 | 右下角開關，側欄收合式，正體中文摘要 |
| Toast | 頂部短暫訊息（取代中央常駐訊息） |

## 狀態矩陣（關鍵）

| 情境 | 畫面反應 |
|---|---|
| 輪到我方、可部署 | 手牌可用卡高亮；PhaseRail CTA 顯示對應動作 |
| 宣告攻擊中 | 攻擊者青光、合法目標琥珀光；中央列顯示「選擇攻擊目標」 |
| 對方回應窗（陷阱/FLIP） | 深色置中提示框；可縮小 dock 看盤 |
| 昏厥/補位 | 提示框逐張詢問；縮小後可點選場上目標 |
| AI 行動中 | 中央列顯示 AI 行動摘要；玩家輸入停用（不變暗整場） |
