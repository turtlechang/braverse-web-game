# Codex 主線與外部協作模板

Codex 是預設主線開發者。先依任務判斷使用 Sol、Terra 或 Luna；只有額度分流、可獨立驗證的低風險平行工、備援或第二意見，才使用 OpenCode Go。確定使用 OpenCode Go 後，再讀 `../../develop-braverse/references/delegation.md`。

## 建議路由

| 任務 | 建議執行者 |
|---|---|
| 核心規則、FSM、AI、線上同步、高風險跨模組修改、最終整合 | Codex Sol |
| 一般功能、單一模組、中型 bug、測試、React、文件同步 | Codex Terra |
| 搜尋、清單、命名、格式、小型低風險修改、既定驗證 | Codex Luna |
| 額度分流、互不重疊的低風險平行工、獨立唯讀審查 | OpenCode Go（選用） |

Sol／Terra／Luna 無法選用時，使用當前可用且足以完成任務的 Codex 模型，不因路由名稱阻塞工作。

## 協作原則

- 一個子任務只交給一個執行者，不重複實作。
- 不讓多個執行者同時修改相同檔案或同一責任區。
- 提供最小但足夠的檔案清單、修改邊界、禁止事項與驗收標準。
- 主線 Codex 負責跨模組決策、diff 整合與最終驗證。
- OpenCode Go 只處理可單獨驗證的工作；不自主決定核心架構、規則或安全行為。
- 外部 HTTPS 與原始碼傳送必須遵循平台核准；核准不可用時停止派工，不得繞過。

## 唯讀第二意見提示

```text
請唯讀審查，不要修改、stage、commit 或呼叫網路。

範圍：
- 檔案：
- 目標：

請依嚴重度列出：
1. 行為錯誤或回歸風險
2. 缺少測試或驗證
3. 安全或提交風險
4. 無法證明正確的假設
```

## 低風險平行實作提示

```text
請直接修改，但不要 stage 或 commit。

任務：
必讀檔案：
允許修改：
不可修改：
驗收標準：
需執行驗證：

請回覆：修改檔案、驗證結果、風險與未確認事項。
```
