# 系列卡牌 Chrome 稽核矩陣

使用這份模板追蹤授權範圍的各色卡牌。依 [實體卡圖與獨立驗收方法](physical-card-verification.md) 逐張核對含 `@` 變體的卡圖；確認文字與效果相同後才可共用案例，不同則拆成獨立列。不要用「已載入」代替「效果已驗證」。

## 稽核標記

| 標記 | 意義 |
| --- | --- |
| `未測` | 尚未在正式戰鬥中操作 |
| `載入通過` | 卡池、卡牌詳情與路由可載入；尚未證明效果 |
| `效果通過` | 依卡面文字完成必要 UI／支付／代價／目標／結算案例 |
| `阻塞` | 有可重現問題，等待修正與回歸 |
| `待確認` | 官方規則或卡面語意不足，暫不自行實作 |
| `N/A` | 該欄位不適用，必須附原因 |
