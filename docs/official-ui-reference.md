## 整合原則

- 採用固定左側階段導覽、中央上下戰鬥區、右側牌庫／場景區。
- 對手與我方皆有獨立手牌、支援區、戰鬥區、休息區、牌庫、場景區與棄牌區。
- 對手手牌在頂部背面扇形排列；我方手牌在右下正面扇形排列。
- 對手支援區位於戰鬥區上方，我方支援區位於戰鬥區下方。
- 被擊倒餅乾在休息區正面疊放，並顯示休息區等級總和。
- 目前階段使用高對比色與箭頭提示，主要操作固定在階段導覽下方。
- 選卡、Refresh、替補與對局結果使用暗幕中央視窗。
- 使用官方紅色、黃色與綠色起始牌組 metadata 中的圖片 URL 呈現牌面。
- 不把整張官方截圖當作背景，也不將來源截圖提交至 repository。

## 響應式調整

官方截圖以 16:9 桌面為主。專案在窄螢幕將階段導覽改為頂部橫列，
戰鬥區保留上下關係，手牌固定在畫面底部並縮小扇形間距。
