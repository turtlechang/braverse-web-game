# BS2 豆子 vs 紫色 — AI 訓練規則

## 對局檔案

- **玩家牌組**: BS2 豆子
- **AI 牌組**: BS2 紫色
- **勝率 (AI)**: 36.0% (18/50)
- **平均回合數**: 15.8
- **卡住場次**: 0

---

## 關鍵發現

### 豆子為何獲勝

1. **陷阱協同**: 豆子的陷阱（BS2-021）提供防禦價值
2. **支援型策略**: 豆子的支援卡隨時間複合累積
3. **後期強度**: 豆子的 Lv3 餅乾在建立後非常強大

### 紫色為何落敗

1. **干擾協同**: 紫色的效果與豆子的緩慢節奏協同良好
2. **節奏控制**: 紫色能控制節奏並阻礙豆子的支援佈局
3. **風行弓箭手 Lv3**: 強大的後期威脅

## AI 訓練規則

### 規則 1：防禦性陷阱使用

```
規則: 豆子對紫色的防禦性陷阱使用
優先級: 高
條件: 紫色攻擊高價值餅乾
動作:
  - 使用陷阱保護 Lv3 餅乾
  - 不要在 Lv1 餅乾上浪費陷阱
  - 考慮每次防禦決定對等級破壞的影響
理由: 保護高價值餅乾能阻止紫色獲得等級破壞進度。
```

### 規則 2：支援卡部署

```
規則: 豆子對紫色的支援卡部署
優先級: 中
條件: 支援階段
動作:
  - 在進入主要階段前部署提升攻擊的道具/舞台
  - 優先選擇影響多個餅乾的卡牌
  - 不要囤積支援卡 — 盡早部署以獲得累積效益
理由: 支援效果隨多個回合複合累積。延遲部署會浪費價值。
```

### 規則 3：等級破壞意識

```
規則: 豆子監控與紫色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：紫色等級破壞 + 我的當前攻擊 >= 10？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：節奏控制

```
規則: 豆子對紫色的節奏控制
優先級: 高
條件: 始終
動作:
  - 不要過度擴展 — 保持場面在可控範圍
  - 使用干擾效果拖慢紫色的佈局
  - 維持手牌優勢以保持靈活性
理由: 紫色的優勢來自干擾。控制節奏能否定其優勢。
```

### 規則 5：致命偵測

```
規則: 豆子對紫色的致命偵測
優先級: 極高
條件: 紫色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 紫色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```
