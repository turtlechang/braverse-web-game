# Wireframe 01 — 戰場（Battlefield）

最後更新：2026-07-19。桌機 ≥900px 版面（P2-1 戰場線稿圖重新設計，四階段 PR 完成後，依實機預覽回饋校正過的現行實作）。可渲染版：dev server 開 `/?mockup=battlefield`。行動裝置（<900px）版面維持本次改版前的既有版面，未變更（獨立的 RWD 深度優化項目留待後續處理）。

## 版面

```
┌──────────┬────────────────────────────────────────┬──┐
│          │ [對手手牌扇形（牌背，戰場區內置中，露出上方 1/3）]  │牌│
│  卡      │ ┌──────────────────────────────────┐    │庫│
│  片      │ │        對手支援區（橫向並列）           │    │場│
│  預      │ │        （由右向左排列）                │    │景│
│  覽      │ ├──────────────────────────────────┤    │棄│
│（hover   │ │        對手戰鬥區                    │    │牌│
│  放大）  │ └──────────────────────────────────┘    │  │
│          ├────────── 中央分隔列：操作指引 ───────────┤ ┌小塊┐
│          │ ┌──────────────────────────────────┐    │目前│
│          │ │        我方戰鬥區                    │    │階段│
│          │ │        （由左向右排列）                │    │結束│
│          │ ├──────────────────────────────────┤    │回合│
│          │ │        我方支援區（橫向並列）           │    └────┘
│          │ └──────────────────────────────────┘    │牌│
│          │      [我方手牌扇形（置中，露出上方 1/2）]   │庫│
└──────────┴────────────────────────────────────────┴──┘
      休息區固定在最左欄（對手/我方各自的休息區，隨列上下）
```

支援／戰鬥區在每列內仍是上下堆疊（支援 45%／戰鬥 55%），維持改版前的比例；牌庫／場景／棄牌與休息區依對手/我方左右鏡射（對手：休息在右、牌庫等在左；我方：休息在左、牌庫等在右），維持改版前的既有規則。詳見下方區域規格。

## 區域規格

| 區域 | 行為 |
|---|---|
| 卡片預覽（hover 浮窗） | 純 hover 觸發的浮動面板，不再是常駐佔用左欄寬度的元件；無 hover 時完全不渲染（`.table-area` 因此改為全螢幕寬度），有 hover 時顯示於畫面左上角（`min(300px,24vw)`，貼近參考的 Master Duel 大卡圖位置），優先顯示目前 hover 的卡、無 hover 時退回顯示對手最近行動的卡；行動裝置（<900px）維持隱藏 |
| 目前階段（貼於中央分隔列右側的小區塊） | 是 `.table-divider`（中央分隔列）的子元素、相對它 `right:0` 定位，垂直置中並溢出到相鄰欄位（對手休息區右上、我方牌庫/場景/棄牌欄右下之間）；區塊內上排文字顯示「回合數」（TURN N），下排顯示「目前階段名稱」，我方回合底色藍、對手回合底色紅；不再列出 5 階段進度清單或逐階段提示文字，也不再有獨立的回合數列（併入上排）；下方為既有的動態「下一步」按鈕。此區塊與相鄰欄位的外緣留白有部分重疊，但兩欄置中對齊的實際可視內容都在重疊範圍外，不影響點擊 |
| 中央分隔列 | 攻擊宣告、付款選擇、目標選擇的提示唯一集中處；平時顯示簡短操作指引；「目前階段」小區塊巢狀其中 |
| 支援／戰鬥 | 每列內上下堆疊（支援 45%／戰鬥 55%），維持改版前比例；戰鬥區橫置＝已攻擊，HP/ATK 徽章常駐，可行動卡青色光暈；支援區橫置＝已付款能量，我方由左向右、對手由右向左排列 |
| 休息區 | 依對手/我方左右鏡射（對手在右、我方在左），以「×N」堆疊樣式呈現數量，點擊仍可開啟完整卡片列表 |
| 牌庫／場景／棄牌 | 依對手/我方左右鏡射（對手在左、我方在右），為數字牌堆 + hover 浮層（場景橫置狀態），棄牌/牌組清單開大型視窗 |
| 角落資訊卡（頭像/名稱/先後攻/狀態） | 定位在整體版面的真實screen角落（對手右上、我方左下，`.field-stack` 全高範圍內鏡射，不受限於戰鬥區自身高度），與同側的休息區同一角落；新增圓形佔位頭像（玩家名稱首字母，無真實頭像素材） |
| 手牌 | 扇形，於戰場區內置中對齊（不再貼右）；卡片尺寸較改版前放大（132px，各響應式斷點依比例放大）；只露出部分高度（`overflow:hidden` 開窗）——對手手牌露出上方 1/3、我方手牌露出上方 1/2，其餘裁切於視窗外；選取後抬升並顯示單一合法動作按鈕；空白處或 `Escape` 取消；不可操作卡降權顯示 |
| 行動按鈕群 | 「結束回合」（中央分隔列右側小區塊下方）、選單（重置/查看牌組/暫停）與戰鬥紀錄開關集中於畫面右下角，彼此不重疊 |
| Toast | 頂部短暫訊息（取代中央常駐訊息） |

## 狀態矩陣（關鍵）

| 情境 | 畫面反應 |
|---|---|
| 輪到我方、可部署 | 手牌可用卡高亮；右欄「下一步」按鈕顯示對應動作 |
| 宣告攻擊中 | 攻擊者青光、合法目標琥珀光；中央列顯示「選擇攻擊目標」 |
| 對方回應窗（陷阱/FLIP） | 深色置中提示框；可縮小 dock 看盤 |
| 昏厥/補位 | 提示框逐張詢問；縮小後可點選場上目標 |
| AI 行動中 | 中央列顯示 AI 行動摘要；玩家輸入停用（不變暗整場） |

## 已知的刻意範圍限制

- 行動裝置（<900px）版面維持本次改版前的既有版面（卡片預覽隱藏、階段列與行動按鈕群回退為改版前定位、手牌貼右且不裁切），未套用本次桌機版新版面；RWD 深度優化留待獨立項目處理。
- 支援區「+1/回」等固定資源生成、戰鬥區「IP」代幣等皆非既有規則引擎概念，本次未新增對應機制。
- 支援/戰鬥橫向並列、牌庫等統一右欄兩項曾短暫實作後依使用者對照原始線稿圖的回饋還原，現行版面為上下堆疊＋左右鏡射（見上方版面圖）。
- 「目前階段」小區塊曾短暫實作為獨立浮動於 `.game-shell` 的區塊，後依回饋改為巢狀在中央分隔列（`.table-divider`）內；`turn-indicator` 內容也從「玩家/對手名稱＋階段」調整為「回合數＋階段」，移除原本重複顯示回合數的獨立元素。
- 本輪 Master Duel 排版參考調整（大卡圖 hover 浮窗、手牌放大、角落頭像）尚未同步更新上方版面圖與 `src/ui-reference/BattlefieldMockup.tsx` 可渲染版；文字區域規格表已反映最新行為，圖示與 mockup 待下次改版一併校正。
