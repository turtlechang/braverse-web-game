# BS5 五色正式 Browser 實戰矩陣（2026-08-07）

## 測試範圍

- 環境：本機正式入口 `http://127.0.0.1:5173/`
- 玩家牌組：BS5 紅／黃／綠／藍／紫「標準賽制」正式牌組
- AI 牌組：各色對應的 BS5 標準 preset，Lv.4
- 本次未使用 `test-state`；每場均由主選單進入正式對戰流程。

## 完整流程

每場均實際經過或驗證以下流程：

1. 猜拳；包含平手重猜與勝者選擇先攻／後攻。
2. 起手調度與起始餅乾放置。
3. 支援階段、主要階段、結束階段與回合推進。
4. AI 攻擊宣告、陷阱回應與「不發動」分支。
5. 傷害結算、HP 卡翻開與餅乾昏厥。
6. 昏厥後補位與新餅乾 `OnPlay`。
7. `OnPlay` 的代價支付、目標選擇與確認發動。
8. 對手棄牌公開資訊的「確認並繼續」流程。
9. 對局結束勝負提示。

## 測試過程修正

- 猜拳勝利後的「選擇先攻／後攻」是正式流程必要分支，已納入 Browser 控制流程。
- 對手因效果棄牌後的公開資訊視窗需要按「確認並繼續」，已納入流程，確認後可正常進入下一階段。
- 控制批次逾時時，對局本身仍持續進行；後續改為短批次接續確認，避免把 Browser 控制逾時誤判為遊戲卡死。

## 限制

本矩陣是五色各 2 場的正式 Browser 端到端 smoke 實戰，不等同於每色 40 場，也不取代固定 seed AI benchmark。玩家方多數回合採合法的略過支援／主要階段操作，因此仍需另外做以自然抽牌觸發每張 BS5 卡牌的逐卡 Browser 覆蓋。
