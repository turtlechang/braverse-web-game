# Braverse 任務契約

本模板用於補足缺失資訊或壓縮交接，不是每次工作必填的新檔案。已由對話確認的內容直接重用。

## 分類

`rules`（規則／卡牌）、`ui`（React／互動）、`ai`（決策／完整對戰）、`tests`（驗證工具）、`git-review`（diff／提交）、`docs-workflow`（文件／AGENTS／Skill）。可依影響範圍複選，不因分類延後安全的下一步。

## 最小契約

```text
目標與完成定義：
背景、必要素材與目前證據：
允許範圍／不可修改／授權門檻：
需跑驗證（依 verification-levels.md）：
目前工作、依賴或阻塞：
現行追蹤入口（若已有）：
```

簡單任務在對話內確認後直接執行。複雜任務沿用一份短計畫；只有資訊不足且影響成果或授權時，集中詢問最多 3 題。

## 唯讀任務

列出讀取範圍與待解問題，輸出結論、檔案／行號證據、已確認與假設、建議修改及缺口。不可將「唯讀」解釋成允許寫報告、fetch、建置、產生快取或啟動服務；依使用者的具體授權處理。

## 分派與交接

不在本模板複製派工提示；確定需要子代理時讀 [唯一派工契約](delegation-template.md)。交接沿用目前入口，留下完成範圍、最後驗證證據、阻塞及下一個具體動作。
