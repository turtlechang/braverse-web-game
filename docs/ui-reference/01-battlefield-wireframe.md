# Wireframe 01 — 戰場（Battlefield）

最後更新：2026-07-19。桌機 ≥900px 版面（P2-1 戰場線稿圖重新設計，四階段 PR 全部完成後的現行實作）。可渲染版：dev server 開 `/?mockup=battlefield`。行動裝置（<900px）版面維持本次改版前的既有版面，未變更（獨立的 RWD 深度優化項目留待後續處理）。

## 版面

```
┌──────────┬───────────────────────────────────────────────────┬────────┐
│          │ [對手手牌扇形（牌背，戰場區內置中）]                        │        │
│  卡      │ ┌──────────┬──────────────────┬──────────────────┐ │  目前  │
│  片      │ │對手支援區 │ 對手戰鬥區          │ 休息（×N）        │ │  階段  │
│  預      │ └──────────┴──────────────────┴──────────────────┘ │        │
│  覽      ├───────────────── 中央分隔列：操作指引 ─────────────────┤        │
│（hover   │ ┌──────────┬──────────────────┬──────────────────┐ │  結束  │
│  放大）  │ │我方支援區 │ 我方戰鬥區          │ 休息（×N）        │ │  回合  │
│          │ └──────────┴──────────────────┴──────────────────┘ │        │
│          │            [我方手牌扇形（置中，選取後抬升）]              │ [選單] │
└──────────┴───────────────────────────────────────────────────┴[紀錄]──┘
```

牌庫／場景／棄牌不再左右鏡射，雙方統一在整體版面最右側（對手列右上、我方列右下，垂直鏡射）；休息區固定在最左側。詳見下方區域規格。

## 區域規格

| 區域 | 行為 |
|---|---|
| 卡片預覽（左欄） | 單一常駐面板，取代原本兩個角落小面板；優先顯示目前 hover 的卡，無 hover 時退回顯示對手最近行動的卡，兩者皆無時顯示「Hover Preview」提示；行動裝置（<900px）維持隱藏 |
| 目前階段（右欄） | 只顯示「回合數＋目前階段名稱」，我方回合底色藍、對手回合底色紅；不再列出 5 階段進度清單或逐階段提示文字；下方為既有的動態「下一步」按鈕（自動階段顯示「自動進行中」、可操作階段顯示對應的略過/結束動作，最終即為結束回合） |
| 中央分隔列 | 攻擊宣告、付款選擇、目標選擇的提示唯一集中處；平時顯示簡短操作指引 |
| 支援／戰鬥／休息 | 每列橫向三區並列（取代先前的上下堆疊）：支援區在左、戰鬥區在中、休息區在右；戰鬥區橫置＝已攻擊，HP/ATK 徽章常駐，可行動卡青色光暈；支援區橫置＝已付款能量，我方由左向右、對手由右向左排列；休息區以「×N」堆疊樣式呈現數量，點擊仍可開啟完整卡片列表 |
| 牌庫／場景／棄牌 | 雙方統一置於整體版面最右側（對手右上、我方右下），不再依對手/我方左右鏡射；為數字牌堆 + hover 浮層（場景橫置狀態），棄牌/牌組清單開大型視窗；彈出視窗一律往左展開，避免超出畫面 |
| 手牌 | 扇形，於戰場區內置中對齊（不再貼右）；選取後抬升並顯示單一合法動作按鈕；空白處或 `Escape` 取消；不可操作卡降權顯示 |
| 行動按鈕群 | 「結束回合」（右欄下方）、選單（重置/查看牌組/暫停）與戰鬥紀錄開關集中於畫面右下角，彼此不重疊 |
| Toast | 頂部短暫訊息（取代中央常駐訊息） |

## 狀態矩陣（關鍵）

| 情境 | 畫面反應 |
|---|---|
| 輪到我方、可部署 | 手牌可用卡高亮；右欄「下一步」按鈕顯示對應動作 |
| 宣告攻擊中 | 攻擊者青光、合法目標琥珀光；中央列顯示「選擇攻擊目標」 |
| 對方回應窗（陷阱/FLIP） | 深色置中提示框；可縮小 dock 看盤 |
| 昏厥/補位 | 提示框逐張詢問；縮小後可點選場上目標 |
| AI 行動中 | 中央列顯示 AI 行動摘要；玩家輸入停用（不變暗整場） |

## 已知的刻意範圍限制

- 行動裝置（<900px）版面維持本次改版前的既有版面（卡片預覽隱藏、階段列與行動按鈕群回退為改版前定位、手牌貼右），未套用本次桌機版新版面；RWD 深度優化留待獨立項目處理。
- 支援區「+1/回」等固定資源生成、戰鬥區「IP」代幣等皆非既有規則引擎概念，本次未新增對應機制。
