# Phase 1 — 視覺變體

最後更新：2026-07-12

依計畫交付視覺變體，皆採「深藍 + 青色全息 + 琥珀警示」基礎方向，差異在氛圍與使用情境。

> 套用方式：在 `<html data-theme="...">` 或 `<body data-theme="...">` 設定。**`tactical-clean` 為預設**（自 2026-07-12 起，因原版 `tactical` 反映太花俏）。

## 變體一：戰術深空原版（`tactical`，對照組）

定位：原始電競科幻戰術桌，保留所有裝飾元素：標題漸層（粉→黃）、按鈕漸層背景、全息 box-shadow glow、32px 棋盤格、大寫寬 letter-spacing 標籤。

| 屬性 | 數值 |
|---|---|
| 背景底色 | `#020817`（近黑深藍） |
| 面板底 | `#0b1d3e` |
| 主色 | `#7ee7f0`（青色全息） |
| 警示 | `#f3b937`（琥珀） |
| 標題 | `linear-gradient(90deg, #ff9db8, #ffd66f)` + 文字剪裁 |
| glow | `0 0 0 1px + 0 6px 24px` 雙層陰影 |
| 質感 | 32px 淺青格線 6% 透明度 |

適用：當你想要最大化「電競感」氛圍時。

## 變體一·b：戰術深空 Clean（`tactical-clean`，預設）

定位：同樣色系但收掉裝飾，**資訊優先**。

| 屬性 | 差異（原版 → clean） |
|---|---|
| 標題 | 漸層 → 純文字（`--color-text-primary`） |
| glow | 雙層陰影 → 1px outline |
| 棋盤格 | `0.06` → `0.02` 透明度（接近不可見） |
| 按鈕 | 漸層背景 → 純 `--color-primary-soft` |
| 卡片背景 | 半透明 `rgba(7,27,61,.78)` → 實心 `--color-bg-panel` |
| letter-spacing | `0.12em` → `0.04em` |
| 主色 | `#7ee7f0` → `#6fdde6`（降飽和） |
| 警示 | `#f3b937` → `#e9b13a`（降飽和） |

你於 2026-07-12 反映 tactical 變體太花俏後新增的優化版。

適用：預設主場。對戰、牌組編輯、線上房間都採此變體。

## 變體一·c：戰術深空 Mono（`tactical-mono`，極簡對照組）

定位：完全去掉青色 / 琥珀點綴，純灰階，證明資訊層不需要顏色也能閱讀。

| 屬性 | 數值 |
|---|---|
| 主色 | `#d9e2ee`（淡灰） |
| 警示 | `#b0b8c4`（中灰） |
| 邊框 | 灰階三層 |
| 陰影 | 完全關閉 |
| letter-spacing | 0（無標籤效果） |

適用：對照組，確認資訊結構不依賴顏色。

## 變體二：低眩光（`low-glare`，夜間 / OLED）

定位：把背景壓得更深、字體對比拉高，適合長時間遊玩或 OLED 螢幕。

## 變體二：低眩光（`low-glare`，夜間 / OLED）

定位：把背景壓得更深、字體對比拉高，適合長時間遊玩或 OLED 螢幕。

| 屬性 | 差異 |
|---|---|
| 背景底色 | `#010410`（更深） |
| 面板底 | `#06183e` |
| 主色 | `#65e8ff`（更亮） |
| 文字次要色 | 對比 0.85（比預設 0.78 更高） |
| 陰影強度 | 加深（不透明度 +50%） |

適用：夜間使用、視力敏感、OLED 防烙印。

## 變體三：賽事廣播（`broadcast`，錄影 / 直播）

定位：放大字體、強化對比、發光更強，適合 OBS 截圖或賽事轉播。

| 屬性 | 差異 |
|---|---|
| 面板底 | `#0b2a61`（更亮） |
| 字級 | base 1.02 / md 1.12 / lg 1.32 / xl 1.65 |
| 主色 | `#71e9ff`（更亮更藍） |
| 警示 | `#ffd159`（更亮） |
| Glow 強度 | 加深 45% |

適用：錄影、實況、競賽播報。

## 套用範例

```tsx
// 永久切換
document.documentElement.dataset.theme = 'tactical-clean'

// 透過 useEffect 動態切換
useEffect(() => {
  document.documentElement.dataset.theme = theme
}, [theme])
```

## 驗證方式

1. 同一張主選單截圖套用 5 個主題，比對差異是否符合描述。
2. 透過 `src/styles/tokens.css` 的 `:root` 與 `[data-theme=...]` selector 集中調整，無需改元件。
3. CI 截圖比對工具（如 Playwright 視覺回歸）應輸出 5 張 baseline。
4. dev 預覽：`/?mockup=themes`（一次看到 5 個 iframe 並列）。
