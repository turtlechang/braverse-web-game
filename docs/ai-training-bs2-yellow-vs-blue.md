# BS2 黃色 vs 藍色 — AI 訓練規則

## 對局檔案

- **玩家牌組**: BS2 黃色
- **AI 牌組**: BS2 藍色
- **勝率 (AI)**: 52.0% (26/50)
- **平均回合數**: 15.0
- **卡住場次**: 0

---

## 關鍵發現

### 黃色為何獲勝

1. **手牌干擾**: 黃色的棄牌效果拖慢藍色的連擊佈局
2. **平衡打法**: 黃色混合進攻與干擾
3. **節奏適中**: 黃色不過度擴展，保持等級破壞在可控範圍

### 藍色為何落敗

1. **佈局較慢**: 藍色的海精靈餅乾 Lv3 需要時間建立
2. **依賴抽牌**: 藍色需要穩定抽牌來維持手牌優勢
3. **前期脆弱**: 藍色的前期餅乾是黃色的理想目標

## AI 訓練規則

### 規則 1：早期手牌干擾

```
規則: 早期干擾藍色手牌
優先級: 高
條件: 第 1-6 回合，藍色手牌 3 張以上
動作:
  - 在藍色建立場面之前發動棄牌效果
  - 以藍色的關鍵組件為目標（抽牌卡、高等級餅乾）
  - 不要在低價值目標上浪費干擾
理由: 藍色的優勢來自手牌優勢。早期干擾能嚴重削弱其佈局。
```

### 規則 2：目標選擇

```
規則: 集中傷害在弱小藍色餅乾
優先級: 高
條件: 藍色戰鬥區有多個餅乾
動作:
  - 將攻擊集中在藍色最弱的餅乾直到擊倒
  - 不要將傷害分散到多個餅乾
  - 擊倒後立即轉向下一個最弱目標
理由: 擊倒餅乾有助於達成等級破壞上限。分散傷害會浪費攻擊。
```

### 規則 3：等級破壞意識

```
規則: 監控與藍色的等級破壞競賽
優先級: 高
條件: 雙方等級破壞都在 6 以上
動作:
  - 計算：藍色等級破壞 + 我的當前攻擊 >= 10？
  - 若是，發動致命攻擊
  - 若否，優先考慮防禦 positioning
  - 追蹤還需要幾次擊倒才能獲勝
理由: 等級破壞上限是主要勝利條件。競賽意識可避免輸掉對局。
```

### 規則 4：前期侵略

```
規則: 對藍色的前期侵略
優先級: 中
條件: 第 1-8 回合
動作:
  - 立即部署最高等級的餅乾
  - 每回合都發動攻擊（如果合法）
  - 放置能提升攻擊傷害的支援卡
理由: 藍色的佈局較慢。施加前期壓力能阻止其建立場面。
```

### 規則 5：致命偵測

```
規則: 對藍色的致命偵測
優先級: 極高
條件: 藍色等級破壞 >= 9
動作:
  - 計算總可用傷害
  - 若總傷害 >= (12 - 藍色等級破壞)，發動致命攻擊
  - 優先選擇能將等級破壞推過上限的攻擊
  - 若有致命機會，不要在非致命目標上浪費攻擊
理由: 對局由等級破壞上限決定。錯失致命機會是落敗的首要原因。
```
