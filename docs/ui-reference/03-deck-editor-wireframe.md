# Wireframe 03 — 牌組編輯器（Deck Editor）

最後更新：2026-07-10。可渲染版：`/?mockup=deck-editor`。

## 版面（桌機）

```
┌──────────────────────────────────────────────────────────────────┐
│ [← 返回] 牌組名稱（可編輯）              [匯入JSON][匯出JSON][儲存] │
├──────────────────────────────── ┬─────────────────────────────────┤
│ 卡池（左，主區）                 │ 牌組側欄（右，固定寬）            │
│ ┌搜尋____________┐              │ 張數  57 / 60  ⚠ 還差 3 張      │
│ 顏色[全部▼] 類型[全部▼]          │ FLIP 14 / 16   餅乾卡 22 ✓      │
│ 費用[全部▼] 稀有度[全部▼]        │ ─────────────────────────       │
│ ┌────┬────┬────┬────┬────┐      │ 不合法原因：                     │
│ │卡  │卡 2│卡  │卡 4│卡  │      │ ・總張數需為 60（目前 57）        │
│ │ ⓘ │徽章│ ⓘ │徽章│ ⓘ │      │ ─────────────────────────       │
│ ├────┼────┼────┼────┼────┤      │ 已選卡牌清單（依費用排序）        │
│ │卡  │卡達4張→禁用樣式│…  │      │ 2×ST1-001 餅乾A     [－]        │
│ └────┴────┴────┴────┴────┘      │ 4×ST1-002 餅乾B(上限)[－]       │
│ （grid 捲動；單擊=加入 1 張）     │ …（捲動）                       │
└─────────────────────────────────┴─────────────────────────────────┘
```

## 行為規格

| 元素 | 行為 |
|---|---|
| 卡池卡片 | 單擊加 1 張；右下角顯示已選張數徽章；右上 ⓘ 開詳情 modal（含加減控制）；達 4 張＝禁用樣式但保留可見 |
| 篩選 | 搜尋（名稱/卡號）＋顏色/類型/費用/稀有度下拉，複合生效 |
| 側欄 | 即時顯示總張數、FLIP、餅乾數；不合法原因逐條列出（60 張整、同卡 ≤4、餅乾 ≥1、FLIP ≤16） |
| 匯入 | 錯誤 JSON 顯示錯誤訊息、不 crash、不覆蓋現有內容 |
| 儲存 | localStorage 版本化格式（`version:1`），自動遷移舊格式 |

## 狀態

- 合法：側欄綠勾＋「可用於對戰」。
- 不合法：⚠ 原因清單；主選單對應牌組顯示「需調整」。
- 空牌組：側欄引導文案。
