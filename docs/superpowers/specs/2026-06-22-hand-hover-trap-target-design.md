# 手牌 Hover 與陷阱合法目標修正設計

## 目標

降低我方手牌 hover 的視覺位移，並修正 ST5-021 在沒有合法目標時仍被玩家 UI 與 AI 判定為可發動，導致對局停在陷阱回應階段的問題。

## 手牌 Hover

- 保留卡牌原本的 `--fan-x`、`--fan-y` 與 `--fan-rotation`。
- hover／鍵盤 focus 時只在原位置額外上移 8px，縮放為 1.02，並保留輕微亮度提示。
- 點擊選取後的 `is-selected` 位移、轉正、縮放與操作按鈕維持現況。

## 陷阱候選

- `getTrapCandidates` 作為玩家 UI 與 AI 的共同合法性來源。
- 對每張陷阱的必選目標效果檢查合法候選數；合法候選少於 `target.min` 時，不將該陷阱列入候選。
- ST5-021 的 `field-to-trash` 必須有至少一張剩餘 HP 2 以下的對手餅乾，才可出現在陷阱回應。
- `target.min = 0` 的可選目標陷阱，以及無目標陷阱，不受此篩選影響。

## 驗證

- 新增 ST5-021 無合法目標時不列入候選的回歸測試。
- 新增 ST5-021 有合法目標時仍可發動並正確移除目標的測試。
- 新增紫色對紫色固定種子 6、19、29、33 的完整 AI 對局回歸測試。
- 驗證 hover 的 CSS 合約保留扇形變數，只額外上移 8px並縮放 1.02。
- 執行完整單元測試、lint、build 與瀏覽器驗證。
