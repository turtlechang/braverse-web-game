# 系列卡牌 Chrome 稽核矩陣

使用這份模板追蹤單一系列的紅、綠、藍、紫卡牌。效果稽核以去除 `@` 變體的基礎卡號為主；變體若文字或效果不同，拆成獨立列。不要用「已載入」代替「效果已驗證」。

## 稽核標記

| 標記 | 意義 |
| --- | --- |
| `未測` | 尚未在正式戰鬥中操作 |
| `載入通過` | 卡池、卡牌詳情與路由可載入；尚未證明效果 |
| `效果通過` | 依卡面文字完成必要 UI／支付／代價／目標／結算案例 |
| `阻塞` | 有可重現問題，等待修正與回歸 |
| `待確認` | 官方規則或卡面語意不足，暫不自行實作 |
| `N/A` | 該欄位不適用，必須附原因 |
