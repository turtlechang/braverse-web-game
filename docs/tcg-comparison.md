# 市面數位 TCG 對標分析（TCG Comparison）

最後更新：2026-07-10。目的：對標但不抄襲，萃取可落地到本專案的互動模式。「本專案現況」欄以 2026-07 的 UI 為基準。

## 1. 逐款分析

### Pokémon TCG Live — 場區清楚、卡牌放大、操作提示

| 值得學 | 本專案現況 | 差距與行動 |
|---|---|---|
| 場區用色塊與留白劃分，一眼可辨主動/備戰區 | 55/45 戰鬥/支援區固定比例，戰鬥卡靠中央分隔列 | ✅ 已達類似清晰度 |
| 任意卡牌長按/hover 放大到可讀全文 | 戰鬥卡 hover 快速預覽面板；手牌選取後抬升 | ⚠️ 支援區與對手卡的放大預覽較弱（改進項 W1） |
| 可行動卡牌閃光邊框 + 引導箭頭 | 可行動高亮、選取後才顯示合法動作 | ✅ 概念相同；箭頭指向不採用（桌面點選足夠） |

### MTG Arena — 回合節奏、動畫、可行動提示

| 值得學 | 本專案現況 | 差距與行動 |
|---|---|---|
| 階段軌（phase strip）+ 停留點提示 | 左側 PhaseRail 五階段 + 精確 CTA（略過支援/結束主要/結束回合） | ✅ 等價設計 |
| 「你需要回應」的全螢幕焦點切換 | 深色置中提示框 + 可縮小 dock | ✅ 已達成；dock 提供比 Arena 更好的看盤能力 |
| 動畫短促、可加速 | 攻擊抖動、抽牌滑入、傷害閃爍、昏厥縮小 | ⚠️ 無「跳過動畫」設定（改進項 W2，動畫已短，優先度低） |

### Yu-Gi-Oh! Master Duel — 場地沉浸感、特效、階段提示

| 值得學 | 本專案現況 | 差距與行動 |
|---|---|---|
| 桌墊材質感、卡牌陰影營造實體感 | 深藍漸層滿版桌墊，卡牌有邊框但陰影層次淺 | ⚠️ 視覺質感可加一層卡牌投影與桌墊紋理（改進項 W3） |
| 連鎖（chain）視覺化 | 效果順序 pending 決策以清單呈現 | ✅ 功能等價，視覺較樸素可後續美化 |
| 大特效 | 不採用——與「快速可讀」定位衝突 | 明確不做 |

### Marvel Snap — 快速、爽感、資訊壓縮

| 值得學 | 本專案現況 | 差距與行動 |
|---|---|---|
| 單畫面容納全部資訊、零捲軸 | 滿版無捲軸畫布（1600×900～600×338 驗證） | ✅ 已達成 |
| 數字變化的彈跳回饋 | HP/ATK 徽章有更新但無彈跳動畫 | ⚠️ 數值變化微動畫（改進項 W4，低優先） |
| 極短的單局時長 | 完整 TCG 回合制，不追求 | 明確不做 |

### Disney Lorcana 類型（Lorcana / Altered 等新世代）— 乾淨桌面、童話感

| 值得學 | 本專案現況 | 差距與行動 |
|---|---|---|
| 低飽和柔和底色 + 高對比卡牌 | 深藍底 + 官方卡圖，對比足 | ✅ 方向一致 |
| 童話/甜點氛圍裝飾元素 | 幾乎無裝飾（純功能） | ⚠️ 「甜點戰場」氛圍：桌墊紋理、圓角、糖果色 accent 點綴（改進項 W3/W5，不犧牲可讀性） |

## 2. 共同模式歸納（本專案的驗收基準）

1. **玩家永遠知道現在能做什麼**：階段指示 + CTA + 可行動高亮 + 不合法即時錯誤。→ 已達成，持續守住。
2. **任何卡牌兩步內可讀全文**：hover/點擊放大。→ 部分達成（W1）。
3. **回應時機全螢幕聚焦、但可看盤**：深色 modal + dock。→ 已達成。
4. **零捲軸單畫面**。→ 已達成。
5. **動畫服務資訊、可跳過**。→ 大致達成（W2）。
