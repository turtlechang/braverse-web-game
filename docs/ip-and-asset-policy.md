## 2. 素材清單與使用方式

| 素材 | 來源 | 目前使用方式 | 風險 |
|---|---|---|---|
| 卡牌圖像 | 官方網站 `cookierunbraverse.com` | **熱連結** `imageUrl`，不在 repo 內、不經 build 打包 | 公開部署即展示官方 IP；官方改版即缺圖（R8） |
| 卡牌文字資料（卡號、名稱、效果文字） | 官方 API 匯入 → `data/cards/*.json` | 入 repo，供規則引擎轉接 | 資料事實層，風險較低，但仍屬官方內容 |
| 卡背、能量圖示 | 官方素材 | `public/` 目錄，隨站部署 | 直接散布官方圖像，風險高於熱連結 |
| 規則文件 | 官方《綜合規則》等 | 僅摘要與裁定記錄於 docs/，不重製原文 | 低 |

## 3. 使用原則

1. **最小必要**：只使用讓對局可玩、可研究所需的素材；不建立官方圖像的打包下載或再散布管道。
2. **來源明示**：卡牌資料保留官方卡號與出處欄位，不去識別化冒充原創。
3. **熱連結優先於複製**：卡圖維持官方網址熱連結；若未來需要快取，須連同 PUBLIC_MODE 一併決策。
4. **下架配合**：若權利方提出異議，立即移除相關素材或關閉公開部署。

## 4. PUBLIC_MODE（已決策：暫不實作）

2026-07-10 專案決策：**維持官方卡圖熱連結現狀，不實作 PUBLIC_MODE placeholder；若收到權利方異議再處理**（配合 §3.4 下架配合原則）。

保留原構想供未來需要時採用：build 時以環境變數（如 `VITE_PUBLIC_MODE=1`）將卡圖 `imageUrl` 替換為本地生成 placeholder（卡號＋名稱＋顏色＋費用的純文字卡面），卡背/能量圖示改用自製幾何圖形；卡牌文字資料照常使用，對局功能不受影響。
